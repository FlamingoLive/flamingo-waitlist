# Flamingo Live

Flamingo Live is a web application designed to facilitate live streaming and selling for users. It provides a user-friendly interface for sellers to manage their accounts, schedule live streams, and interact with their audience.

## Features

- User-friendly FAQ section with expandable answers.
- Smooth animations for a better user experience.
- Responsive design for various screen sizes.
- Easy navigation to different sections of the application.

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **Framer Motion**: A library for animations in React applications.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **React Icons**: A library for including icons in React applications.

## Installation

To get started with the project, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://https://github.com/FlamingoLive/flamingo-waitlist
   ```

2. Navigate to the project directory:

   ```bash
   cd flamingo-waitlist
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open your browser and go to `http://localhost:5173` to view the application.

## Usage

- Navigate through the FAQ section to find answers to common questions.
- Click on the questions to expand and view the answers.
- Use the "To the Top" button to quickly scroll back to the top of the page.
